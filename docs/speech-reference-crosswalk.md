## Task 7 receipt contract

`swift run oigo-issue10-contract-tests --filter 'speech reference cross surface'` exercises the joined regression.
When `OIGO_TASK7_EVIDENCE_DIR`, `OIGO_SOURCE_SHA`, and `OIGO_INTEGRATED_SHA` are set, it writes one JSON receipt per scenario plus `speech-reference-cross-surface-receipt.json`.
Every receipt contains the pinned reference SHA, source SHA, integrated SHA, scenario, generation, verdict, cleanup counts, and deterministic evidence class.
Receipts contain no transcript, audio, clipboard, target identity, filesystem payload, permission result, or user content.
